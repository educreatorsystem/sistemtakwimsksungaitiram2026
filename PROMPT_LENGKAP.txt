SUMBER DATA
Untuk paparan biasa, ambil data daripada URL CSV Google Sheet. Tambahkan cache busting timestamp. Gunakan parser CSV yang menyokong quoted fields dan koma dalam teks.
Jangan gunakan localStorage sebagai database.
Jika CSV gagal, fallback kepada Apps Script action=list jika URL Web App sudah dikonfigurasi.

LOGIN ADMIN
Apabila pengguna menekan Sunting Takwim, buka modal login dengan ID dan password.
Frontend menghantar POST text/plain ke Apps Script:
{ action:"login", id:"...", password:"..." }
Apps Script melakukan pengesahan dan memulangkan token sesi.
Simpan token sahaja dalam sessionStorage. Jangan simpan password.
Token mempunyai tempoh sesi dan semua operasi add/update/delete/generatePoster mesti memerlukan token.

TAMBAH PROGRAM
Apabila admin aktif, setiap hari mempunyai butang +.
Buka modal dengan medan:

- Kategori
- Catatan

POST:
{ action:"add", token, date, title, time, place, category, notes }

SUNTING PROGRAM
Klik program dalam mod admin untuk membuka maklumat sedia ada.
POST:
{ action:"update", token, id, date, title, time, place, category, notes }

PADAM PROGRAM
Paparkan confirmation dahulu.
POST:
{ action:"delete", token, id }

Selepas add/update/delete, refresh data melalui Apps Script action=list tanpa reload keseluruhan halaman dan kekalkan bulan semasa.

Paparkan lencana sekolah, nama sekolah, nama bulan, tahun, kalender dan program.
Sembunyikan semua butang, modal, toast dan loading indicator semasa print.

AI POSTER BULANAN
Fungsi AI hanya aktif selepas login admin supaya API key/quota tidak boleh digunakan oleh orang awam.

Apabila admin menekan Jana Poster AI:
1. Frontend menghantar month/year/token kepada Apps Script action=generatePoster.
2. Apps Script membaca sendiri data sebenar bulan tersebut daripada Google Sheet.
3. Jika tiada program, pulangkan mesej “Tiada program direkodkan untuk bulan ini. Poster tidak dapat dijana.”
4. Apps Script membina prompt berdasarkan program dan kategori bulan tersebut.
5. Apps Script memanggil Gemini Image API menggunakan model gemini-3.1-flash-image.
6. AI HANYA menjana ilustrasi hero 16:9 tanpa sebarang teks, nombor, logo, watermark atau lencana.
7. Apps Script memulangkan ilustrasi base64 serta data program sebenar.
8. Frontend menggunakan HTML Canvas untuk membina poster akhir dengan saiz 1600×2000.

PENTING: Jangan minta AI menulis senarai program terus ke dalam imej kerana AI boleh tersalah eja. Semua teks poster mesti dilukis oleh Canvas berdasarkan data Google Sheet.

GEMINI BACKEND
Gunakan Google Gemini Interactions API:
POST https://generativelanguage.googleapis.com/v1beta/interactions
Header x-goog-api-key daripada Script Properties.
Model: gemini-3.1-flash-image
response_format image/jpeg, aspect_ratio 16:9, image_size 1K.
Parse schema semasa melalui steps[].content[] dan cari blok type=image dengan data base64. Tambah fallback untuk schema lama jika perlu.
