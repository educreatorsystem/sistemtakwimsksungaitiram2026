# Sistem Takwim Sekolah 2027 — Versi Tanpa AI

Sistem ini telah dibersihkan daripada semua fungsi Jana Poster AI.

## Konfigurasi
- Tahun: 2027
- Sekolah: SEKOLAH KEBANGSAAN SUNGAI TIRAM
- Google Sheet: Takwim2027
- Apps Script URL telah dimasukkan dalam `app.js`.

## Fungsi
- Paparan takwim Januari hingga Disember 2027
- Data program daripada Google Sheet/CSV
- Login admin
- Tambah, sunting dan padam program
- Refresh data
- Cetak bulan dipilih dalam A4 landscape
- Paparan responsif desktop, tablet dan telefon
